# 🌸 منصة زهور ريفان | Rivan Flowers
منصة إلكترونية متكاملة لبيع وتنسيق باقات الورد الطبيعي والهدايا الملكية مع لوحة تحكم إدارة شاملة.

---

## 🌟 أبرز مميزات المنصة

### 💐 1. واجهة المتجر وتجربة العملاء (Storefront):
- **تصميم عصري فاخر**: لوحة ألوان مستوحاة من رقة الورد (Rose, Pastel, Emerald) وتنسيق RTL كامل باللغة العربية مع خط Cairo الفاخر.
- **تصفح وتصنيف الباقات**: إمكانية تصفية الورد حسب المناسبة (حب ورومانسية، تخرج ونجاح، مواليد، فازات ملكية، ورود وهدايا مع شوكولاتة باتشي).
- **بحث وتصفية ذكية**: بحث مباشر باسم الورد، ونوع الزهرة (جوري، توليب، أوركيد، لافندر)، وسلايدر لتحديد السعر الأقصى، وترتيب المنتجات.
- **تفاصيل الباقة والعناية**: نافذة منبثقة تفاعلية لكل باقة تستعرض مكونات الزهور، تعليمات العناية بالورد، وتحديد الكمية.
- **سلة مشتريات ديناميكية**:
  - شريط متابعة التوصيل المجاني (توصيل مجاني عند تجاوز 350 ر.س).
  - نظام كوبونات الخصم (كوبون `WARD10` يمنح خصم 10% فوري).
  - حفظ محتويات السلة محلياً (LocalStorage).
- **إتمام الطلب (Checkout)**:
  - بيانات المرسل وبيانات المستلم وعنوان التوصيل في مدن المملكة (الرياض، جدة، الدمام، الخبر، مكة، المدينة).
  - **ميزة كرت الإهداء المخصص**: كتابة رسالة شخصية تطبع على كرت كوشيه فاخر مع اقتراحات رسائل جاهزة.
  - **جدولة موعد التوصيل**: اختيار تاريخ التوصيل والفترة المفضلة (صباحية، ظهيرة، مسائية).
  - وسائل دفع متعددة: مدى / فيزا، Apple Pay، والدفع عند الاستلام.
- **نظام تتبع الطلب (Order Tracker)**:
  - تتبع حالة الطلب خطوة بخطوة بالرقم (مثل `ORD-1001`).
  - مراحل تتبع حية: استلام الطلب ➔ جاري التنسيق والتجهيز ➔ خرج للتوصيل ➔ تم التسليم.

### 👑 2. لوحة تحكم الإدارة (Admin Dashboard):
- **إحصائيات وإيرادات مباشرة (KPIs)**: إجمالي المبيعات، عدد الطلبات، الطلبات قيد التجهيز، الطلبات المكتملة.
- **إدارة الطلبات**:
  - جدول تفصيلي بجميع الطلبات الواردة مع فلترة حسب الحالة وبحث بالاسم أو الرقم.
  - استعراض تفاصيل المستلم، الباقات، ورسالة كرت الإهداء المكتوبة.
  - **تحديث حالة الطلب اللحظي** وحفظها في قاعدة البيانات.
- **إدارة باقات الورد (Products Management)**:
  - إضافة باقة جديدة مع الصور والسعر والتصنيف والمكونات.
  - تعديل الأسعار، الوصف، والمخزون المتوفر.
  - حذف الباقات مع رسالة تأكيد.

## 🛠️ البنية التقنية (Tech Stack)

- **الواجهة الأمامية (Frontend)**: React 18, Vite 6, Tailwind CSS, Lucide React Icons.
- **الواجهة الخلفية (Backend API)**: Node.js, Express, RESTful APIs, CORS, Persistent JSON Database.
- **البيئة**: جاهزة ومجهزة للتشغيل على بيئة Windows وجميع المنصات.

---

## 🚀 طريقة التشغيل

### تشغيل الخادم والواجهة:

1. **تشغيل خادم الـ API (Backend)**:
```bash
cd server
npm start
# يعمل على المنفذ: http://localhost:5000
```

2. **تشغيل واجهة المتجر (Frontend)**:
```bash
cd client
npm run dev
# تعمل على المنفذ: http://localhost:5173
```
